Session & Perimeter Security

Enforces modular, strict access control layers. Employs Flask-Login for active session validation and form security layers to block intrusion:

  • Role-Based Access Control (RBAC): Separates permissions cleanly so Admins, Doctors, and Patients only view their authorized templates and endpoints.
  • Password Integrity: Secures user credentials using Werkzeug helper libraries to perform PBKDF2 SHA256 password hashing.
  • Form Validation & CSRF Shields: Powered by Flask-WTF and WTForms to inspect email structures and filter inputs against Cross-Site Request Forgery.

security.py - Authorization Perimeter Guard 
def role_required(*roles):
    def wrapper(func):
        @wraps(func)
        def decorated_view(*args, **kwargs):
            if not current_user.is_authenticated:
                return redirect(url_for('login'))
            if not current_user.has_role(roles[0]):
                flash('Perimeter permission error.', 'danger')
                return redirect(url_for('index'))
            return func(*args, **kwargs)
        return decorated_view
    return wrapper

// Client trigger to submit booked appointment parameters
async function bookAppointment(doctorId, date, time, reason) {
    const response = await fetch('/api/appointments', {
        method: 'POST',
        headers: {
            'Content-Type': 'application/json',
            'X-CSRFToken': getCsrfToken()
        },
        body: JSON.stringify({
            doctor_id: doctorId,
            appointment_date: date,
            appointment_time: time,
            reason: reason
        })
    });
    if (!response.ok) {
        const err = await response.json();
        throw new Error(err.error || 'Server error occurred');
    }
    return await response.json();
}
